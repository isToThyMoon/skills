# 八维观察参考

用下面八个维度扫描语料找候选特征；每个维度产出多少结论由证据决定，维度之间可以交叉。读到候选时追问三件事：它在此处解决了什么表达问题，读者感受怎样形成，换一个情境还适不适用。

- **交际情境与读者关系：** 对谁说、为了什么说，默认多少共同知识；像同事商量、老师讲解还是作者独白。看称呼、人称、解释前提、礼貌程度。"我们"可能是共同探索，也可能把作者判断推广给所有人，结合上下文区分。
- **词汇与句法：** 高频词、虚词、具体与抽象词、动词、省略、句子长度与复杂度、中外文混用；数一下强度词与限定词的比例。内容词和连接词、语气词一起看；主题词高频往往来自题材。观察句子怎样展开、省略了什么，长度只是其中一项。
- **节奏与信息密度：** 长短句怎样交替、哪里停顿、一段推进多少内容、重点是否得到更多篇幅。找句长变化发生的位置，看停顿前后承载的信息：长句可以连贯展开因果，短句可以落下判断，具体作用以材料为准。
- **衔接与篇章组织：** 前一句怎样引出后一句，论点与例子的次序，转折、分节、开头和收束方式。看已知信息如何引出新信息，段落之间靠因果、时间、例证、让步还是重复关键词衔接。区分贯穿全文的习惯和某一体裁的格式。
- **修辞与意象：** 比喻、排比、反问、反讽、重复；意象从哪里取材；修辞承担解释、强调还是情绪。记录触发情境、密度和取材范围，密度高低都记：比喻解释了什么关系，排比是否带来新信息，反问是否要求读者参与判断。
- **立场与情感：** 判断有多确定，怎样表示怀疑、赞同和批评，热情、幽默、严肃如何随对象变化。确定程度、情感强度、评价对象分开看：措辞温和的人可能判断坚定，语气热烈的人可能谨慎限定结论。幽默的对象和时机比"幽默"标签有用。
- **论证与认识习惯：** 从现象、个案、机制还是原则切入；怎样选证据、处理反例、限定结论。找主张、依据和两者之间的推理桥梁；作者断言、引用来源、分析者推测分开记。记录文中对反例、缺证和修正的处理方式；成文之外的思考过程记为未知。
- **对话习惯：** 怎样承接对方、纠正误解、追问、承认未知，何时回答到此为止。以真实话轮及前后回应为准。单篇文章里的"你"支持读者关系分析；小说人物台词按角色和场景处理；作者本人的聊天习惯需要另外的证据。

## 证据强弱

强弱以材料范围为条件，附理由，用这三档表达：

- **较强：** 多个独立片段支持同一选择，跨情境仍能观察到，或用户明确指定采用。用户指定证明的是偏好，作者是否一贯如此另记。
- **有限：** 在少量材料或单一体裁中反复出现，当前范围内可用，跨情境迁移待检验。
- **暂定：** 单次出现、存在反例，或主要来自分析者对作用的解释。作为试写候选，限定情境使用。

证据缺失记为未知：一篇材料中缺少某个具体句式，只说明这次没观察到。密度是另一回事：强度词、比喻、拟人、感叹、对比句式在整批语料里的计数，高低都是证据，按作者的实际分布写成正向规则。密度低的作者写成"判断附条件""比喻只用于解释关系"；密度高的作者写成"每段至少一处夸张""关键判断用最高级"。计数记入证据，规则的方向由语料决定。同一篇文章截出的多个片段算一份证据。统计时写明样本范围、分句或分词口径和归一化单位；字数、分句长度、每段句数比中文词频容易复核。样本分布用于校准，写进指导时表述为倾向。

## 从印象到指导

以下是构造的示例，展示写法。

| 初步印象 | 继续找的证据 | 有证据后的生成指导 |
| --- | --- | --- |
| 克制 | 强判断是否紧随具体依据，结论是否保留范围 | 根据已有事实下判断，把结论限制在事实覆盖的范围内 |
| 有画面 | 场景细节是否帮助理解后面的判断 | 解释抽象问题时，先选一个与核心关系有关的可感知细节，再展开关系 |
| 有节奏 | 关键判断前后句长是否变化 | 复杂说明连续展开；关键判断处收短，给读者停顿 |
| 平等交流 | 是否准确承接对方原话，解释是否考虑已知信息 | 从对方当前卡住的地方接着说，补齐理解下一步所需的信息 |
| 幽默 | 笑点是否来自具体处境、轻微夸张或自嘲 | 在材料支持的轻松场景中，用具体处境里的小反差表达幽默 |

同一种印象可能来自多种写法，采纳哪个动作以本次语料和用户反馈为准。
