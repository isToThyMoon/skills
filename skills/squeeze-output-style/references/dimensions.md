# 八维观察参考

用这张表寻找候选特征。扫描全部维度后，按证据决定哪些进入目标风格；每个维度无需产出同样多的结论。这是用于蒸馏的工作框架，各维度可以交叉。

| 维度 | 语料中值得观察的东西 |
| --- | --- |
| 交际情境与读者关系 | 对谁说、为了什么说；默认多少共同知识；像同事商量、老师讲解，还是作者独白 |
| 词汇与句法 | 高频词、虚词、具体与抽象词汇、动词使用、省略、句子长度与复杂度、中外文混用 |
| 节奏与信息密度 | 长短句怎样交替；哪里停顿；一个段落推进多少内容；重点是否获得更多篇幅 |
| 衔接与篇章组织 | 前一句怎样引出后一句；论点与例子的次序；转折、分节、开头和收束方式 |
| 修辞与意象 | 比喻、排比、反问、反讽、重复；意象从哪里取材；修辞承担解释、强调还是情绪表达 |
| 立场与情感 | 判断有多确定；怎样表示怀疑、赞同和批评；热情、幽默、严肃如何随对象变化 |
| 论证与认识习惯 | 从现象、个案、机制还是原则切入；怎样选择证据、处理反例、限定结论 |
| 对话习惯 | 怎样承接对方、纠正误解、追问、承认未知；何时回答到此为止 |

## 从特征到作用

读到候选特征时，追问它在此处解决了什么表达问题、读者感受如何形成，以及换一个情境后还适不适用。

- **交际情境与读者关系：** 看称呼、人称、解释前提、礼貌程度与共享知识。“我们”可能表示共同探索，也可能把作者的判断推广给所有人，结合上下文区分。
- **词汇与句法：** 同时看内容词和连接词、语气词等功能词。主题词频繁出现往往与题材有关。观察句子的展开方式及省略的内容，避免只看长度。
- **节奏与信息密度：** 找句长变化发生的位置，观察停顿前后承载的信息。一个长句可以连贯地展开因果，短句可以落下判断；具体作用以材料为准。
- **衔接与篇章组织：** 看已知信息如何引出新信息，段落之间凭借因果、时间、例证、让步还是重复关键词衔接。区分贯穿全文的习惯与某一体裁的格式。
- **修辞与意象：** 记录触发情境、出现密度及取材范围。分析比喻到底解释了什么关系，排比是否增加不同信息，反问是否要求读者参与判断。将修辞用于有相应需要的位置。
- **立场与情感：** 分开观察确定程度、情感强度与评价对象。措辞温和的人也可能判断坚定；语气热烈也可能谨慎限定结论。幽默的对象及使用时机比“幽默”标签更有用。
- **论证与认识习惯：** 找主张、依据及从依据到主张的推理桥梁。区分作者的断言、引用来源和分析者推测。记录文中如何对待反例、缺证和修正，不从成文风格推断隐藏的思考过程。
- **对话习惯：** 优先看真实话轮及前后回应。单篇文章里的“你”只能支持读者关系分析。小说人物台词按角色和场景处理，作者本人的聊天习惯需要另外的证据。

## 证据强弱

强弱以材料范围为条件，并附理由；无需给伪精确的置信度分数。

- **较强：** 多个独立片段支持同一选择，跨情境仍能观察到，或用户明确指定采用。用户指定证明的是偏好，不能据此宣称作者一贯如此。
- **有限：** 在少量材料或单一体裁中反复出现，当前范围内可用，跨情境迁移待检验。
- **暂定：** 单次出现、存在相反例子，或主要来自分析者对作用的解释。可作为试写候选，按限定情境使用。

证据缺失记为未知。一篇材料中没有某个句式，无法直接推出禁用规则。同一篇文章截出的许多片段也不能冒充跨文章证据。

统计时写明样本范围、分句或分词口径以及归一化单位。中文词频依赖分词方式；字数、分句长度、每段句数通常更容易复核。只有实际计算过才报告数值，样本分布用于校准，不转写成每篇必须满足的配额。

## 操作化示例

以下为构造的分析示例，展示写法；它们不代表待分析语料的目标风格。

| 初步印象 | 可以继续寻找的证据 | 有证据后可写的生成指导 |
| --- | --- | --- |
| 克制 | 强判断是否紧随具体依据，结论是否保留范围 | 根据已有事实下判断，并把结论限制在事实覆盖的范围内 |
| 有画面 | 场景细节是否帮助理解后面的判断 | 解释抽象问题时，先选一个与核心关系有关的可感知细节，再展开关系 |
| 有节奏 | 关键判断前后句长是否变化 | 复杂说明连续展开；关键判断处适当收短，给读者停顿 |
| 平等交流 | 是否准确承接对方的原话，解释是否考虑已知信息 | 从对方当前卡住的地方接着说，补齐理解下一步所需的信息 |
| 幽默 | 笑点是否来自具体处境、轻微夸张或自嘲 | 在材料支持的轻松场景中，用具体处境里的小反差表达幽默 |

同一种印象可能来自多种写法。采纳哪个动作，以本次语料和用户反馈为依据。
