# Explain — 新概念解释

对 $ARGUMENTS（未提供时取用户当前问的概念）解释。呈现顺序、详略、体裁按概念本身选择：有的概念反例先行，有的代码先行，有的一条时间线就够。

## 硬性动作

1. 示例代码先实际运行再给出，附运行结果；优先零依赖、可直接复制运行。依赖外部服务跑不了的，标注"未运行"。纯理论概念用推演或反例代替代码。
2. 概念较新或快速演化（近两年出现、或大版本迭代频繁）时，用 WebFetch/WebSearch 核实官方文档与主流实现，给出处链接；成熟稳定的概念直接说明依据。
3. 用户陈述了自己的理解时，逐条判定 对/部分对/错，指出错在机制、层次还是术语。没陈述则直接解释。
4. 用户提供 Notion 页面链接时，完整版写入该页面，聊天里给核心结论和关键示例；后续追问的澄清简短同步回文档。

## 覆盖检查单

发送前逐条自查，缺了就补；不适用的项跳过（成熟概念没有"替代方案"就不写）。

- 一句话定义用了用户已知的概念做类比（"X 之于 A ≈ Y 之于 B"）
- 反事实：没有它会怎样
- 时间线：之前的做法卡在哪；现在有什么替代或后继方案，各自适用条件
- 常见误区和不适用场景
