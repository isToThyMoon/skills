## 金融地图

金融解决的核心问题是：资金如何跨时间和参与者流动，风险如何定价、分担与控制，以及交易如何可靠完成。这里先覆盖现代金融的共同骨架：个人与公司金融、投资与资本市场、银行保险等金融机构、支付清算、监管与金融稳定；暂不展开具体国家的税法、产品推荐和交易策略。IMF 对金融系统的概括包括银行、非银贷款机构、保险、证券市场、投资基金、支付与清算机构、央行和监管者。[IMF：Financial System Soundness](https://www.imf.org/en/about/factsheets/financial-system-soundness)

骨架关系是：

> 资金提供者 → 通过金融机构或市场 → 把资金交给资金使用者；合同、价格和抵押品分配收益与风险；支付清算基础设施完成交易；监管、披露和风控约束全过程；实际现金流与损失再反馈到价格和决策。

### 1. 核心实体 Entities

- 家庭、企业、政府｜分别储蓄、融资、投资或支出｜共同形成资金供给与需求。
- 银行、保险公司、基金等金融机构｜汇集资金、提供支付服务并转换期限或风险｜连接储户、借款人和市场。
- 投资者、借款人、发行人｜承担不同现金流权利与义务｜通过股票、债券、贷款等合约发生关系。
- 交易所、清算机构、支付系统｜撮合、确认和结算交易｜降低交易对手与操作风险。
- 央行、监管与监督机构｜维护货币、市场和机构稳健｜规则最终由各司法辖区落地。

### 2. 核心概念 Concepts

- 现金流与货币时间价值｜比较不同时点的钱｜估值本质上是把未来现金流折算到可比较的时点。
- 风险、收益与流动性｜收益通常伴随不确定性，流动性表示资产能否及时、低成本变现｜三者不能脱离场景单独优化。
- 分散化与集中度｜把风险分布到不同来源｜只能减少部分特定风险，不能消除整个市场的系统性风险。
- 杠杆｜用债务或衍生品放大敞口｜既放大收益，也会放大损失和追加保证金压力。
- 信用与期限转换｜机构把短期资金转为较长期融资，并承担违约风险｜由此产生流动性和偿付能力要求。
- 信息不对称与激励｜交易双方掌握的信息和承担的后果不同｜连接披露、抵押、契约条款与监管。
- 定价与价格发现｜市场把现金流预期、风险和供需反映进价格｜估值模型是决策工具，不是确定预言。

### 3. 高频术语 Vocabulary

- Equity / Debt｜股权代表剩余权益；债务约定偿付义务。
- Primary / Secondary Market｜一级市场完成新融资；二级市场让已有证券流通并形成价格。
- Yield / Credit Spread｜收益率描述回报尺度；信用利差反映相对基准的额外信用与流动性补偿。
- Liquidity / Solvency｜流动性关注能否按时付款；偿付能力关注资产长期是否足以覆盖负债。
- Collateral / Margin｜抵押品和保证金用于控制交易对手风险。
- Duration｜衡量固定收益工具对利率变化的敏感度，不等同于简单的到期期限。
- NAV｜基金资产净值，是资产减负债后的单位价值基础。

### 4. 工作流 Workflow

常见流程是：

1. 明确目标、期限、风险承受和法律约束。
2. 收集现金流、资产负债、市场价格与信用资料。
3. 选择融资、投资、保险或对冲方案并估值。
4. 完成审批、披露、交易和结算。
5. 持续监控现金流、风险限额、契约和合规状态。
6. 根据新信息再融资、再平衡、减仓或修订模型。

企业融资更重视资本成本和偿债能力；资产管理更重视组合目标与风险；银行则还要管理资本、流动性和期限错配。

### 5. 常见产物 Artifacts

- 财务报表与现金流预测｜供管理者、债权人和投资者判断经营与偿付能力。
- 估值模型｜把业务假设转成价值区间，并用于情景比较。
- 融资条款书、招股说明书或贷款合同｜规定权利、价格、抵押和违约条件。
- 投资政策书与风险限额｜把目标、允许资产和风险边界变成可执行约束。
- 交易确认、持仓与业绩报告｜证明交易结果并支持核对、归因和审计。
- 信用备忘录、压力测试与监管报表｜记录判断依据并检查极端情境和合规要求。

### 6. 评价指标与判断标准 Evaluation

- 回报｜总回报、收益率、内部收益率等；必须同时说明期间和现金流假设。
- 风险｜波动、最大回撤、违约概率、压力损失等；不同指标观察的是不同风险。
- 风险调整后表现｜把收益与承担的风险放在一起比较，但结果依赖基准和时间窗口。
- 流动性｜买卖价差、成交深度、现金缓冲及变现时间。
- 偿债与信用｜杠杆率、利息覆盖、现金流覆盖和违约情况。
- 机构稳健性｜资本、流动性、资产质量和集中度；不能用单一比率替代整体判断。
- 市场质量｜公平、效率、透明度和系统风险是证券监管的核心目标之一。[FSB 收录的 IOSCO 原则](https://www.fsb.org/work-of-the-fsb/about-the-compendium-of-standards/key_standards/)

### 7. 常见失败模式 Failure Modes

- 流动性错配｜出现集中提款、融资续不上等症状｜需检查现金流期限、抵押品和备用融资，而非立即断言资不抵债。
- 过度杠杆｜小幅价格变化引发大额损失或强制平仓｜检查总敞口、保证金和压力情境。
- 信用集中｜少数客户、行业或地区恶化便造成重大损失｜检查集中度和相关性。
- 利率或汇率错配｜市场变量变化后利润或净值异常波动｜核对资产负债期限和对冲是否匹配。
- 模型与数据风险｜结果对假设极敏感或与实际持续偏离｜回测、情景分析并检查数据来源。
- 激励冲突、误导披露或欺诈｜销售目标与客户利益冲突、重要信息缺失｜检查治理、授权、披露和审计证据。
- 操作、网络与结算失败｜重复付款、交易无法完成或账实不符｜检查权限、对账、业务连续性和交易对手链条。
- 系统性传染｜同类机构同时去杠杆，冲击跨机构扩散｜不能只看单家机构指标。

### 8. 标准与框架 Standards / Frameworks

- Basel Framework｜巴塞尔银行监管委员会制定的银行审慎监管标准集合，覆盖资本、风险、披露和监管原则；由各辖区实施，不是直接适用于所有人的统一法律。[BIS：Basel Framework](https://www.bis.org/committees/bcbs/basel-framework)
- IOSCO Principles｜组织证券监管，核心关注投资者保护、公平高效透明市场和系统风险。
- IFRS Standards｜组织财务报告的国际会计标准；是否及如何采用取决于司法辖区。
- PFMI｜支付系统、中央证券存管、证券结算系统、中央对手方和交易数据库的基础设施原则。
- FATF Recommendations｜反洗钱、反恐融资与防扩散融资框架。
- FSB Compendium｜汇总金融稳定相关的主要国际标准，并明确这些标准仍须结合各国制度实施。[FSB：Key Standards for Sound Financial Systems](https://www.fsb.org/work-of-the-fsb/about-the-compendium-of-standards/key_standards/)

### 用一个案例串起来

企业要扩建工厂时，先形成现金流预测和融资需求；再比较贷款、债券与股权的成本、期限和控制权影响。银行或投资者依据财务信息、抵押和行业风险定价，合同或发行文件记录权利义务；交易通过支付或证券基础设施结算。融资后持续检查现金流、利息覆盖和契约。如果销售下降，先区分短期流动性压力与长期偿付问题，再决定补充资金、重谈条款或缩减项目。

推荐阅读顺序：先掌握“现金流与时间价值 → 风险、收益、流动性 → 财务报表与估值”，再按目标进入公司金融、投资、银行、保险或监管。尚未展开的主要分支包括个人理财、公共财政、货币政策、衍生品、精算、金融科技、数字资产以及各国法律税务。
