## 范围与方法

主 Agent 阅读原方法和已安装旧版，使用 skill-creator、writing-for-agents 编写新版。独立 GPT-5.6 Sol 审查实际指令，并执行 [四个场景](cases.md)。执行者收到用户请求及 skill 路径，未收到参考答案；主 Agent 检查实际输出，针对观察到的缺陷修订规则，再让执行者重做受影响部分。

这些是小样本前向测试与针对性复测，不是盲评对照实验；修订轮已明确指出缺陷，因此只能证明该场景的修订行为，不能证明对所有新场景泛化。没有真实用户学习测试，不产生掌握程度、长期收益或量化质量提升的结论。

## 静态审查处理

| 发现/建议 | 处理 |
|---|---|
| 无具体任务时可能跳过来源核查 | 已要求核查主要分支与现行标准/框架的权威入口 |
| “用户能理解”等完成条件不可直接观察 | 改为输出覆盖、关系与可继续分支的检查 |
| 条目可能只有释义，关系仅出现在结尾 | 补充条目的“名称、用途、明确关系”最小表达 |
| 全景+应用组合请求可能遗漏一个交付物 | 明确先地图、再指定应用，全部满足 |
| 学习状态与练习可选性存在旧措辞 | 最终版本移除“保留未检验”，练习需用户意愿，无档案 |
| 所有请求都必须先输出八类地图 | 未采纳：用户要求全景作为入门方式，未要求在单独翻译任务中强制上课 |
| 用固定小条目数控制长度 | 未采纳硬限制：按主要子域覆盖与用户要求控制，避免再次缩成局部词表 |

## 实际执行

### A：没有项目，建立播客制作地图

[原始输出](outputs/podcast-original.md)实际交付八类内容，说明五个相邻子域，区分节目、RSS 与平台，并用制作流程和转行访谈案例连接实体、产物、质量检查和返工。没有要求先提供项目或先答题。

初轮部分通过：核心结构可用，但将“受众—承诺—格式”和“问题—证据—推进—回报”列为框架，未说明是否为自创归纳。新增来源性质规则后，[定向复测](outputs/podcast-revision.md)明确区分正式标准、平台指南、实务方法与本回答的教学组织方式。该缺陷在复测片段中已修正。

主 Agent 抽查 Apple 音频要求中的格式/响度建议，以及 IAB 官方页面的版本状态，与样例引用相符：[Apple 音频要求](https://podcasters.apple.com/support/893-audio-requirements)、[IAB 正式页面](https://iabtechlab.com/standards/podcast-measurement-guidelines/)、[v2.3 征求意见公告](https://iabtechlab.com/press-releases/iab-tech-lab-releases-podcast-technical-measurement-guidelines-v2-3/)。这是关键主张抽查，不是全文专业审计。

### B：宽领域金融地图

[实际输出](outputs/boundary-original.md)覆盖资金参与者、金融机构、基础设施、现金流与风险、工作流、产物、指标、失败模式及国际标准；给出企业融资案例和阅读路径。明确暂不展开具体国家税法、产品推荐与交易策略，没有把领域缩成股票交易，也没有阻塞在追问项目上。

结构与路由检查通过；该样例不代表金融专家审计或金融建议有效性验证。

### C：没有页面，只想改写“高级一点”

初轮直接给出可复制说明，区分候选问题和未知项，未强制上课。但擅自加入“保持现有功能、内容和基本交互不变”，把未经确认的范围写成硬约束，因此初轮部分通过。对此在 SKILL.md 中补充明确规则，要求限制来自用户或标为暂定建议。

[定向复测](outputs/translation-revision.md)改为将允许改动的范围列入未知项，涉及内容、功能或交互的改动先说明理由与影响；不再冻结它们。保留可观察检查和材料不足时的诊断边界。该缺陷在复测中已修正。

### D：用户表示看懂，结束会话

实际回答：“好，今天先到这里。下次想继续时，直接说‘继续信息层级’并带上当时要分析的材料即可。”没有答题要求、掌握等级、学习档案或自动记忆承诺。通过该场景的行为检查。
