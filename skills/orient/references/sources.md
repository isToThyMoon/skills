# 领域知识的获取与交叉检查

## 1. 用内化知识建立候选结构

利用已有知识拟定主要子域、八类内容、关键关系及值得查证的主张。这是可修订的工作底稿，不必先向用户倾倒两份地图。稳定基础知识可直接解释，不要求每个常识都挂引用；不能将模型记忆伪装成刚读过的材料，或给记忆中的说法编造出处。

优先标出会影响地图结构、领域判断和可执行约束的问题：哪些分支可能遗漏，哪些概念易混淆，哪些建议只有在特定条件下成立，哪些规则依赖版本或地区。用这些问题引导查找，也主动找反例和不同取舍。

## 2. 获取互补资料

新领域地图默认尝试下列途径。顺序可随资料可得性调整，类别是用途而非绝对可信度排名；同一材料可承担多种作用，但不能把多个同源页面当成独立证据。

| 途径 | 选什么资料 | 提取什么，如何影响地图 |
|---|---|---|
| 概览资料 | 有明确作者/机构的学科概览、教材目录、课程大纲、综述或专业组织的领域介绍 | 核对主要分支和相邻领域，补全结构；目录只支持范围，不能代替正文证明具体结论 |
| 规范、标准、官方文档 | 原始规范、发布机构文件、对应版本的产品文档 | 校准名称、定义、规则、范围与版本；规范规定的行为与实际实现分开 |
| 真实专业产物 | 已采用或实际讨论的设计系统、PRD、RFC、ADR、架构文档、研究报告、实现/评审记录 | 提取实际对象、表达、决策、产物及约束；看清专业人士为什么这样选择 |
| Checklist | 来源明确且有适用背景的评审/验收清单 | 提取可观察检查项和遗漏风险；逐项判断条件，不把整份清单升级为必选方案 |
| 失败案例与复盘 | 当事团队的事故复盘、真实可用性研究、缺陷报告、实验失败或有材料支撑的案例分析 | 提取症状、发生条件、原因证据、处置与局限，补充反模式及何时应改选方案 |

真实专业产物需有实际项目/组织及决策背景；一篇介绍“ADR是什么”的文章或空模板不等于实际 ADR。通用反模式文章可以解释机制，但不能冒充真实复盘。自己编的教学案例也不能填补这两类来源的缺口。

查找时使用领域词加具体产物或问题，如“<领域> design rationale / ADR / research findings / review checklist / incident postmortem”；结合发布方官网、公开仓库和原始研究，追到实际材料。官方指南与真实项目可能同属一个组织，需区分规范性主张与项目证据，不能据此宣称广泛共识。

即使用户没有项目，也主动查真实专业产物与失败案例。领域地图的来源不必与贯穿教学案例完全同场景；相邻场景的真实案例也可补充机制和边界，说明可迁移之处与不可直接套用的条件即可。资料缺失、付费或不可访问时，换用可访问的原始资料或合适的案例类型；合理尝试后仍缺少就标明缺口。不要为凑齐类别编造出处、把简介当读过全文，或无限扩大搜索。

## 3. 按主张交叉检查并更新地图

实际读取支持主张的段落或产物内容；搜索摘要用于定位，不能代替对关键主张的核查。尤其逐项核对具体案例、数值和例外是否确实在所引资料中，不能因为页面主题相关就把记忆中的细节挂在该链接下；找不到支持则删除该细节或标为未核实。对重要规则、易混淆概念、风险较高或有争议的判断，比较互补证据，而非给每个词机械找两个链接：

- 规范/研究说明定义与预期；真实产物说明如何采用及代价；失败案例检验适用边界。它们未必研究同一项目，不要伪造因果联系。
- 出现冲突时核对定义、版本、地区、样本、任务和目标。能解释的差异写成条件化结论，仍不能解释的保留争议与不确定性；不按引用数量投票。
- 用新资料补充遗漏分支、修正关系或收窄建议；若资料仅确认原判断，如实写“得到支持”，无需制造观点反转。
- 对效果主张优先查实验、研究或测量；区分作者观点、观察结果和因果证据。一个成功或失败案例不能证明普遍效果。

工作中保留简短的证据对应：资料/版本与场景 → 支持或限制的主张 → 地图/要求中相应内容。可以在当前上下文中维护，无需另建档案；只记录可核查内容，不输出冗长推理过程。

满足以下条件即可收束：主要分支经过概览核对；关键定义/规则有合适依据；真实产物、checklist、失败案例已提供可用内容或显式说明缺口；影响判断的冲突已处理或保留；能说明资料如何支持或改变地图。无需证明已搜尽领域，也不设置链接数量指标。

## 4. 交付时让知识依据可见

保持“总览、八类地图、贯穿案例、导航”四部分。关键主张附近给具体出处和适用范围；在导航中简短列出“资料带来的补充/修正与仍缺的证据”，让读者看见真实产物或失败案例如何影响一个概念、关系或要求，而非只收到一张书单。可将资料用途合并说明，避免重复正文。

区分模型已有知识的解释、读到的事实、综合判断和教学假设。无需给每句基础解释贴标签，但不能把综合归纳写成来源的原话，或把未核验的记忆写成当前官方要求。来源链接不等于已证明整张地图。

无法联网且无外部材料时仍可基于内化知识交付有边界的候选地图，并明确“未做外部核查”、待确认的时效性规则与来源缺口。已有用户材料可实际检查，但不得声称完成了不存在的检索。用户明确禁止联网时遵守其要求。
